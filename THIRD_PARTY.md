# Third-party / AI-assisted disclosure

## Code

- Written in Swift / SwiftUI with Apple system frameworks only: SwiftUI, AppKit, AVFoundation, CoreText, CryptoKit.
- No third-party Swift packages, no external SDKs, no network services.
- Development was assisted by AI coding tools (DeepSeek Harness / AI assistant) for implementation and debugging. All final code was reviewed and built by the team.

## Video / poster

- The demo video uses the macOS `say` system voice (Tingting) for Chinese narration, plus in-app rendered frames. This voice is generated locally by Apple's system TTS and is not redistributed as an audio asset.
- The competition poster must be generated separately with AMD's image-generation API. The raw AMD image and AMD Creative Factory Gallery screenshot are submitted as separate proof; they are not part of this source repository.

## Fonts

- The app uses system fonts: PingFang SC / SF Pro / Songti SC (when available). No font files are bundled.
